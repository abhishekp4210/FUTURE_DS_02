# FUTURE_DS_02
Customer Retention &amp; Churn Analysis Dashboard using Microsoft Excel. This project analyzes customer churn patterns, retention trends, revenue insights, and customer tenure using pivot tables, charts, KPI cards, and interactive slicers. The dashboard provides business insights and recommendations to improve customer retention and reduce churn.
# Customer Retention & Churn Analysis

## Project Overview
This project analyzes customer retention and churn patterns for a subscription-based business using Microsoft Excel. The dashboard helps identify customer churn behavior, revenue trends, and retention drivers through interactive visualizations and data analysis.

---

## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Dashboard
- Data Cleaning & Analysis

---

## Project Features
- Customer churn analysis
- Revenue analysis by contract type
- Customer tenure analysis
- Interactive dashboard with slicers
- KPI cards for business metrics
- Insights and recommendations for reducing churn

---

## KPI Metrics Included
- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate
- Retention Rate
- Total Revenue

---

## Dashboard Components
### 1. Churn by Contract Type
Analyzes churn across different contract types.

### 2. Churn by Internet Service
Identifies which internet services have higher customer churn.

### 3. Revenue Analysis
Shows revenue generated from different contract types.

### 4. Customer Tenure Analysis
Analyzes customer retention trends based on tenure.

---

## Key Insights
- Month-to-month contract customers have the highest churn rate.
- Fiber optic users show higher customer churn.
- Long-term contracts improve customer retention.
- Customers with shorter tenure are more likely to leave.

---

## Recommendations
- Encourage customers to switch to yearly contracts.
- Improve onboarding and customer support.
- Provide loyalty rewards and discount offers.
- Focus on retaining low-tenure customers.
